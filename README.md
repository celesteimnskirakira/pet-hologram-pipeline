# 跟屁宠 · Pet Hologram Companion

> 让宠物的动作被看见、被记录，也继续陪伴在主人身边。

“跟屁宠”是基于**宠物健康监测项圈实时姿态识别能力**二次开发的全息陪伴项目。系统将项圈识别到的宠物动作与行为状态映射到桌面全息宠物，使主人即使不在宠物身边，也能通过一个持续同步的数字分身感知它的状态与陪伴。

本仓库提交的是黑客松期间用于快速验证全息视觉效果和现场交互流程的 **Demo 实现**。正式版的实时姿态识别、项圈数据链路和动作映射系统不在本仓库中开源。

## 为什么做“跟屁宠”

宠物健康监测项圈已经能够持续采集运动数据，并识别睡觉、趴卧、坐立、行走等姿态。我们进一步思考：

**如果这些原本只出现在健康报告里的姿态数据，也能变成一种有温度的实时陪伴，会发生什么？**

在正式产品中：

- 宠物在家睡觉，桌面的全息宠物也进入睡眠状态。
- 宠物起身活动，全息宠物同步切换相应动作。
- 项圈持续记录健康和行为数据，全息桌宠把数据转化为直观、轻量、具有情感连接的反馈。

这使健康监测从“事后查看数据”，延伸为“日常能够感受到的陪伴”。

## 正式版系统

正式版建立在已有项圈姿态识别能力之上，核心工作不在视频生成，而在于打通从真实宠物到全息分身的实时链路。

```text
宠物佩戴健康监测项圈
        ↓
传感器持续采集运动与姿态数据
        ↓
实时姿态识别与行为状态判断
        ↓
宠物身份、动作和状态映射
        ↓
全息桌宠切换对应动画
        ↓
主人看到与真实宠物同步的数字分身
```

| 系统层 | 作用 |
| --- | --- |
| 宠物健康监测项圈 | 持续采集与宠物运动、姿态相关的数据 |
| 实时姿态识别 | 将连续信号判断为睡觉、趴卧、坐立、活动等行为状态 |
| 状态同步与动作映射 | 将识别结果转成全息端动作指令，并处理动作持续、切换和异常状态 |
| 个性化宠物资产 | 保留不同宠物的外观特征，建立专属数字形象与动作资源 |
| 全息显示终端 | 接收状态并播放对应动作，让数字宠物持续呈现在桌面上 |
| 健康与陪伴体验 | 将同一份行为数据用于健康观察和情感化反馈 |
